# ASC conceptual illustrations — public set

These are the three high-level drawings reproduced on pages 6–8 of the 28-page ASC Preprint 0.2.

- `ASC-001_Full_Structure_Section.png`: schematic full-structure section.
- `ASC-002_Orthographic_General_Arrangement.png`: conceptual views.
- `ASC-003_Exploded_Assembly.png`: schematic exploded arrangement (correct drawing number).

Concept and source direction: **P. Gabor**. All three illustrations were prepared with generative-AI assistance. The apparent dimensions, joints, fasteners, materials and construction details are not verified. These are not CAD or fabrication drawings, not photographs of built hardware, and not a depiction of measured system performance.

Use these corrected public versions rather than earlier drawings bearing the wrong number. Rights and licensing remain subject to the repository's prepublication checklist.

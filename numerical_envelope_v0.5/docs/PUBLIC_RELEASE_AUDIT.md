# v0.5 public release audit and caveats

- This package was assembled from v0.4 PUBLIC source materials only, plus explicitly user-provided hypothetical recovery assumptions. The confidential v0.3 ZIP was **not** copied or read as a source for this release.
- No verified proprietary ASC coupler, dimensions, frequencies, circuitry, controller coefficients, assembly instructions or CAD exported. All numbers are disclosed generic, *hypothetical*.
- Power bins in the hybrid exercise are assumed disjoint; no claim the channels can be measured that way in a real system. RF already returned upstream must not be captured twice.
- Carnot and radiative calculations establish ideal thermodynamic constraints, not a demonstrated TEG or thermal architecture.
- Reported useful output is an abstract accounting metric, not thrust, lift, speed, or experimental benefit. The mass penalty scaling is explicitly counterfactual.
- Test execution proves internal numerical consistency; no measured hardware validation or independent peer review has occurred.
- Verify license, attribution and any patent concerns before publishing. Publishing can harm patent options.
- Do not upload confidential research files.
